# KAN-MIMIC

## Project Overview
This project investigates the use of standard Kolmogorov-Arnold Networks (KANs)
for clinical prediction using a preprocessed MIMIC-IV dataset.

The main objective is to compare KAN against CatBoost under the same
experimental conditions.

## Models
- Standard Kolmogorov-Arnold Network (KAN)
- CatBoost baseline

## Research Workflow
1. Dataset inspection and validation
2. Feature and target verification
3. Consistent patient-level data splitting
4. CatBoost implementation
5. KAN implementation
6. Model evaluation and comparison

## Data
Clinical datasets are stored outside this repository and must not be committed
to GitHub.

## Reproducibility
Model configurations, experiment settings, and evaluation procedures will
be documented in this repository.
